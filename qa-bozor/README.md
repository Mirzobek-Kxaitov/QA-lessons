# QA Bozor

Static QA vacancy dashboard served at `/qa-bozor` inside QA Academy.

Edit HTML/CSS/JS here; `data.json` is a collected snapshot, not a live API. Data collection time and coverage are displayed in the dashboard. Automatic collection is not configured by this integration.

Preview from repository root: `python3 -m http.server 8851` then open `/qa-bozor/`. Assets use the `/qa-bozor/` prefix so Vercel clean URLs work with or without a trailing slash.

Main and Russian homepage navigation link here. Production follows the existing repository deployment integration.
